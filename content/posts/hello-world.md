这是一篇 **示例文章**,用来展示博客的 Markdown 排版效果。把 `content/posts/` 下的 `.md` 文件替换成你自己的内容即可。

## 支持的语法

你可以使用:

- 无序列表 / 有序列表
- **加粗**、*斜体*、~~删除线~~
- [链接](https://example.com)
- 行内 `code` 与代码块
- 表格、引用、分隔线

### 代码块

```ts
export function greet(name: string) {
  return `你好,${name}。`;
}
```

### 引用

> 最好的时间是十年前,其次是现在。

### 表格

| 栏目 | 说明 |
| ---- | ---- |
| 关于 | 自我介绍与联系方式 |
| 作品 | 项目展示 |
| 博客 | 写作与技术笔记 |
| 简历 | 工作经历与技能 |

---

想要新文章,只需在 `content/posts/` 下新建一个 `.md` 文件,带上 frontmatter 即可。
